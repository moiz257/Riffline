# Riffline

Riffline is a musician collaboration platform for discovering bandmates, open positions, creative projects, and local music scenes.

## Highlights

- Musician and band discovery
- Profiles with instruments, genres, gear, and media
- Band listings and applications
- Messaging and connections
- Calendar and collaboration planning

## Stack

React, Vite, React Router, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
